# Orbit Ledger

A small offline web app for launch notes, a delta-v scratchpad, and a pad checklist.

Open it at https://kampfguy.github.io/OrbitLedger/ and, on iPhone, tap Share then Add to Home Screen.

Files: `index.html` (the app), `manifest.json`, `sw.js` (offline cache), `icon-192.png`, `icon-512.png`.
